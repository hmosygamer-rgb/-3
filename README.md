# قريب

تطبيق ويب تقدّمي (PWA) عربي وخفيف لمشاركة الموقع بين أفراد العائلة **بموافقتهم**، مصمم للهواتف والأجهزة المكتبية ويعتمد على Google Maps.

## التشغيل

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173`.

## الخصائص

- واجهة عربية RTL متجاوبة وقابلة للتثبيت على أندرويد.
- عرض أفراد العائلة ومواقعهم على Google Maps.
- فتح الاتجاهات مباشرة في Google Maps.
- تحديد موقع المستخدم مع إعدادات مقتصدة للطاقة (`maximumAge` مرتفع وبدون GPS عالي الدقة).
- دعوات مشاركة خاصة ومبنية على الموافقة.
- مناطق آمنة، سجل نشاط، حالة البطارية، وتنبيهات.
- Service Worker للتشغيل السريع ودعم العمل دون اتصال للواجهة.
- وضع داكن يدوي وتلقائي حسب إعداد الهاتف مع حفظ الاختيار.
- مشروع Android أصلي خفيف داخل `android/` مع صلاحيات الموقع وفتح الاتجاهات في Google Maps.
- حالة بداية فارغة تماماً؛ لا يظهر أي فرد قبل إنشاء دعوة له.
- تحديد موقع عالي الدقة عند الطلب باستخدام GPS مع إظهار الدقة بالمتر وإيقاف الاستماع تلقائياً لتقليل استهلاك البطارية.
- ويدجت شاشة رئيسية مصغّرة، قابلة لتغيير الحجم ومتوافقة بصرياً مع Samsung One UI والوضعين الفاتح والداكن.
- مركز لإدارة أذونات Android الضرورية: الموقع التقريبي والدقيق والخلفي، الكاميرا لمسح QR، الإشعارات، خدمة الموقع الأمامية، الشبكة، الاهتزاز، والاستعادة بعد تشغيل الهاتف.
- إنشاء QR لكل دعوة، مشاركته، ومسحه مباشرة بالكاميرا أو من صورة محفوظة؛ تتم القراءة محلياً ويُرفض أي رمز ليس رابط دعوة صالحاً من «قريب».

لا يطلب التطبيق أذونات لا تستخدمها وظيفته (مثل الرسائل وجهات الاتصال والكاميرا والميكروفون)، التزاماً بخصوصية المستخدم وسياسات Google Play.

## ملف APK

ملف التثبيت الجاهز موجود في جذر المشروع باسم **`Qareeb.apk`** (موقّع ومتحقق منه بتواقيع APK ‏v1/v2/v3). ولإعادة بناء مشروع Android محلياً مع JDK 17 وAndroid SDK:

```bash
cd android
gradle :app:assembleDebug
```

الناتج المحلي: `android/app/build/outputs/apk/debug/app-debug.apk`.

> بيانات أفراد العائلة في النسخة الحالية تجريبية ومحفوظة في الواجهة. يحتاج الإنتاج إلى خدمة خلفية آمنة، مصادقة، قاعدة بيانات لحظية، وإدارة مفاتيح Google Maps من خلال متغيرات بيئة، بالإضافة إلى تطبيق Android أصلي لجمع الموقع في الخلفية وفق سياسات Android وموافقة المستخدم الواضحة.
